# Update the roadmap

This command is the **only sanctioned way scope moves**.

## Steps

1. **Establish what actually exists.** Read the recent commit log, the roadmap and `docs/STATE.md`. The update describes **reality, not intention** — if a slice is half done, it says which half.
2. **Update the roadmap.** Mark what is done, and check each done milestone's acceptance criteria, in the owner's terms. **Keep every milestone's out-of-scope list intact**: done items move to done, excluded items never silently vanish.
3. **Process any scope change.** Apply it **only after the founder confirms**, and record it as its own decision file with a line in the index.
4. **Replace `docs/STATE.md`** — never append. Under __MKTRUE_BUDGET_STATE__ characters.

## Done when

The roadmap matches reality, every scope change has a decision file, and the state file is replaced and inside its budget.
